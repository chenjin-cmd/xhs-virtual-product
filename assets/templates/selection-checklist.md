# 选品判断表

> 复制本表，对每个候选方向逐项打分（✅ / ⚠️ / ❌），6 项全绿才值得做。

| 维度 | 判断问题 | 合格标准 | 本方向结果 |
| --- | --- | --- | --- |
| 需求 | 用户是否已经在搜索或评论区表达需求？ | 有明确求资料、求模板、求方法、求工具的信号 |  |
| 制作 | 我能否在 1-3 天做出初版？ | 不依赖大量开发或复杂版权资源 |  |
| 交付 | 用户付款后能否清楚拿到结果？ | 链接、PDF、模板、知识库或工具入口清晰 |  |
| 展示 | 能否用封面和内页展示价值？ | 一眼能看出解决什么问题 |  |
| 合规 | 是否涉及版权、机构资料、站外导流或夸大宣传？ | 风险可控，资料来源清楚 |  |
| 迭代 | 是否能根据评论和订单继续升级？ | 有扩展包、版本升级或系列化空间 |  |

## 三个常见误区（先自检）

- [ ] 我是否在反复纠结、超过 2 天还没定方向？（定方向 ≤ 2 天）
- [ ] 我是否在"确定能卖出去之前"就花半个月打磨产品？（先出雏形再上架）
- [ ] 我是否一个品没发几篇笔记就频繁换品？（跑通闭环或验证真的不好卖再换）
