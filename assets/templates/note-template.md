# 商品笔记模板

> 复制本模板写商品笔记。封面/标题决定点击，正文做"导购"而非"写作文"。

## 标题
`[人群] + [痛点/结果] + [资料/模板/工具]`

（套用 `title-formulas.md` 的 5 类公式生成变体，去重微调 10-20%）

## 封面
- 大字标题：
- 副标题：
- 展示图：资料目录 / 效果截图 / 前后对比 / 清单局部
- 比例：3:4 竖图；配色 ≤ 3 种；背景简洁

## 内页结构（4-6 张图）
1. 适合谁
2. 能解决什么问题
3. 里面包含什么
4. 使用步骤
5. 使用前后对比
6. 常见问题
7. 商品入口提醒

## 正文（弱引导，别像营销文）
我整理了一个 [资料/模板/工具]，主要适合 [人群]。
如果你现在遇到 [痛点]，可以先看这套资料里的 [具体模块]。
它不是万能答案，但能帮你少走 [具体弯路]。
已经放在商品里，按需自取。
