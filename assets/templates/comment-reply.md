# 评论区互动话术模板

> 评论区是小红书变现的"收银台"。公式：人设故事 + 商品链接。别一上来就发"看主页"，要做"过来人"。

## 通用 3 段式（蓝字可替换）
1. **立人设（痛点共鸣）**：我是 XX，曾经也是个 [极度讨好型 / 容易内耗 / 不知如何沟通] 的人，这种痛苦我太懂了。
2. **摆结果（建立信任）**：后来通过大量学习和实践，我终于 [摆脱了困境 / 摸清了底层逻辑 / 不再内耗]。
3. **给诱饵（顺势推品）**：为了帮大家少走弯路，我把这些经验做成了一份 [17万字社会化指南 / 潜意识测试工具]，希望能帮到你。
4. **挂链接**：在评论区点"+"→ 商品，选择对应商品。

## 高频问题应答
- 用户问：哪里可以看 / 怎么买？
  → 回复：我已经放在商品里了，可以点笔记里的商品入口看详情。
- 用户问：适合新手吗？
  → 回复：适合新手，我做的时候按从 0 开始的步骤整理了，里面有 [模块] 和 [示例]。
- 用户问：后续会更新吗？
  → 回复：会根据大家反馈继续补充，当前版本主要解决 [核心问题]。
- 用户提出新需求：
  → 回复：这个需求很好，我先记下来，后续可以考虑做成补充模块。

⚠️ 不要站外导流、不要留联系方式、不要夸大效果。
