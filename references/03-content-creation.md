# 小红书内容创作

核心逻辑：封面和标题先获得点击，再用内页、正文、话题和商品挂车完成转化。虚拟产品尤其依赖搜索流量和精准需求表达。

> 笔记主要包含：封面、内页、标题、正文、话题。点击率看封面+标题（第一性原理）；质量大于数量，别花大量时间写正文却随意写标题/封面。

## 一、工具准备（可选，非必须）
- **AI 工具**：Gemini / GPT / Kimi / DeepSeek 等，用于写文案、做测试网页、生成翻译与词汇。
- **做图工具**：稿定设计、美图设计室、可画（Canva）——任选顺手的一个。
- **违禁词检查**：零克查词、句无忧、句易网（每次发文前必查，机器+人工双审核）。
> 具体平台/工具可能变化，以官方为准；工具是手段不是目的。

## 二、笔记类型
- **互动笔记**：测试账号是否正常（小眼睛 200+）、拉活跃度、测需求（发 UI 界面看是否"求链接"）。
- **干货笔记**：提供价值（知识/技巧/教程/清单/避坑），收藏 > 评论，长尾流量稳，可挂蓝链带动销量。
- **商品笔记**：销量好坏的核心，精准流量，有搜索属性，封面够吸引人就容易卖。

## 三、封面设计
- **比例 3:4 竖图**（黄金比例，展示面积大）。
- **吸睛三要素**：视觉冲击（色彩明亮、背景简洁、配色 ≤3 种）；信息明确（大字报点核心）；3:4 竖图。
- **4 类爆款封面**：
  - **大字报**：快速吸睛、抛痛点。高对比底色 + 巨大文字。适合测试/知识库/资料。
  - **实拍**：展现高级、场景包装。第一视角开箱/桌面摆拍。适合工具/模板/测试。
  - **截图**：建立信任、展示结果。产品界面/结果页原生截图。适合测试/工具/资料。
  - **干货**：建立专业度、拉高收藏。思维导图/横测/SOP。适合工具/知识库/资料。

## 五、内页做法
内页充当产品介绍和钩子，核心公式：**给出框架，隐藏结论；制造痒点，提供解药。**
- **四步截图连环法**：① 痛点代入图（最扎心的题目/吐槽）→ ② 半遮半掩结果图（模糊核心结论）→ ③ 买家秀（评论/聊天截图打消顾虑）→ ④ 傻瓜式指路图（红箭头指向入口）。
- **题库悬念法**：只给输入不给输出，纯题目截图步步紧逼（沉浸式闯关）。
- **维度目录法**：适用于资料/知识库，先展示丰富目录（"卖懂你"），再展示 SOP/话术/表格（"卖实操"）。

## 六、正文（做导购，不是写作文）
- 封面给人看，正文给算法看（埋 SEO 关键词）。
- 用 AI 写：先把产品投喂给 AI 熟悉，再让其写种草笔记。结构：开头痛点引入 → 中间价值锚点（Emoji 列表化）→ 结尾行动指令（**弱引导**，别写"快点击下方购买"易被判定营销文，用描述价值来做弱引导）。
- 核心逻辑：用最短时间建立信任、展示价值、指引下单。

## 七、话题（金字塔选词法）
话题是"和算法接头的条形码"，决定推给谁：
- **塔基（大类，1-2）**：#职场 #个人成长 #心理学
- **塔腰（精准，2-3）**：#I人 #社恐 #infp
- **塔尖（痛点场景，2-3）**：#不会聊天怎么办 #高情商沟通
- **塔顶（热点，1-2）**：#新春市集 #我的治愈系生活（带"热"字、官方扶持）

## 八、评论区（变现的"收银台"）
公式：人设故事 + 商品链接。通用 3 段式（立人设 → 摆结果 → 给诱饵 → 挂链接）。详见 `assets/templates/comment-reply.md`。
> 别站外导流、别留联系方式、别夸大效果；乱发广告会被限流封号。

## 九、产品挂车
内容做好后：添加组件 → 商品 → 选择商品 → 下一步。刚发布有审核时间，可发自己微信里打开查看状态（"笔记审核中"→ 能看到即发布成功）。
