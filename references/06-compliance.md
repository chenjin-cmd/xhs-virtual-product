# 合规原则与版权红线

> 这是整个 Skill 的底线。任何选品、制作、上架、发文动作，都必须先过本章。违规不是"赚多赚少"，而是"账号被封、保证金被扣、所有积累付诸东流"。

## 一、合规原则（总纲）
虚拟资料产品的底线：**只做原创、合规产品。**
- 不售卖侵权资料；不搬运带版权、机构标识、水印、授权限制的内容。
- 不使用站外导流、虚假宣传、夸大收益、诱导交易等高风险表达。
- 案例用于理解产品/内容逻辑；真正实操用**自己的资料、自己的整理、自己的交付体系**。

## 二、版权三大雷区（坚决不碰）

### 1. 明确版权归属的内容
- 各类正规出版物电子版（扫描版畅销书、教材、绘本）。
- 影音课程与录播课（得到、喜马等平台；新东方、学而思等机构网课）。
- 知名 IP 的衍生产品（未经授权售卖迪士尼、动漫人物等形象的设计素材）。
- 破解软件 / 安装包（享有软件著作权）。

### 2. 带显著机构标识的资料
任何清晰印有某学校、某培训机构、某出版社 Logo、水印的资料，都视为其资产，整理分享风险极高。

### 3. 有明确版权声明的资源
标注"所有权归 XX 所有，未经许可不得复制、传播、销售"的资源，最好不碰。

## 三、平台受限产品（时效性强，以官方为准）
部分「电子资源」类目（如 PPT 模板/简历/课件/头像壁纸等）可能实行**定向准入**，对个人店/企业店有入驻时长、内容量、流水、资质等门槛（示例：个人店可能要求入驻 ≥180 天、笔记 ≥30 篇、粉丝 ≥1000 等；企业店另有注册资本、执照年限要求）。**具体门槛与生效时间以小红书千帆后台 / 官方电商学习中心当前规则为准，无资质普通人可能无法上架，不推荐死磕。**

## 四、发布前合规检查清单
每次上架商品或发笔记前，用 `assets/templates/compliance-checklist.md` 逐项打勾：
- [ ] 资料来源清楚（自己整理/原创，非搬运）
- [ ] 不含机构水印、课程资料、出版物扫描件或未经授权内容
- [ ] 商品标题不夸大效果
- [ ] 笔记正文不出现站外联系方式或导流表达
- [ ] 不承诺收益、结果、录取、考试通过等不可保证事项
- [ ] 商品详情说明交付形式、适用人群、使用边界
- [ ] 已查平台违禁词
- [ ] 已确认当前类目和资质规则

## 五、心态兜底
第一个产品不需要完美，首要目标是**跑通闭环**，体验从选品、上架、做笔记到真实出单的完整流程。只要跑通一次，就超越 90% 的空想者。
