# 店铺开通与运营

> ⚠️ 时效提醒：本章涉及类目、保证金、资质、准入门槛的规则变化极快。本文件只保留**方法论骨架**，具体数值、条件、费用一律以小红书千帆后台（ark.xiaohongshu.com）与官方电商学习中心当前规则为准。执行前务必复核。

## 一、开店准备

### 1. 设备与号
- 手机：能正常用、不卡即可，前期用一个号跑通流程再考虑加设备。
- 手机卡：干净、未注册过小红书的号；账号/手机/手机号尽量一一对应。
- 电脑：前期非必须，后期产品制作、店铺后台、订单处理更方便。
- 网络：稳定正常，前期建议移动流量，避免同 WiFi 违规连坐。

### 2. 账号四件套（主页辨识度）
- **昵称**：简单清晰好记，能看出方向。参考：名字+赛道（"小林做副业"）、名字+身份（"小红书运营教练安安"）、赛道场景（"AI工具箱"）。
- **头像**：干净明确、缩小能看清、风格统一，不频繁换。
- **简介**：一进主页就知道"这个账号是干嘛的"——写清内容方向 / 能提供价值。
- **背景图**：与账号方向一致、风格统一即可，默认也行。

### 3. 注册与养号
- 注册后能正常登录、浏览、互动、发布。
- 养号：像真实用户浏览/搜索/点赞/收藏，建立自然使用行为；头像/昵称/简介分三天设置，减少改动。
- 账号检测：我 → ≡ → 帮助与客服 → 账号检测，查是否禁言/限流/异常。
- 实名：一个人只能实名一个账号，不急，确定选品、需开店时再实名。

## 二、店铺类型（方法论）
- **个人店**：身份证 + 实名小红书号，审核快。部分类目受限。
- **个体店**：个体户营业执照（经营范围含互联网销售 / 教育咨询等），可做的类目更广。
- **企业店**：公司执照，涉及税务，一般个人/小团队可忽略。

> 新号建议先个人店跑通，再按需求升级个体店；具体门槛、费用、升级条件以官方为准。

## 三、商品上架（骨架）
1. **主图**：稿定/可画制作，JPG/PNG，1:1 或 3:4，≤5M；图片空间建主图/详情图文件夹分类。
2. **类目与资质**：商品名模仿对标（16-60 字符，不带违禁词）；选对类目（成人教育 / 儿童教育等），缺资质按官方要求补办或合规代办。
3. **商品信息**：商品描述 + 详情页（展示详情、声明虚拟资料不退不换）；建物流模板（无物流也需建）、现货、发货时间；填售价库存、建多个 SKU。
4. **交付与发货**：虚拟资料多用自动发货（如第三方自动发货服务，配置以官方文档为准）。虚拟资料**不退不换**，别勾七天无理由。

## 四、店铺运营（骨架）
- **装修**：店铺装修处配新人券、设商品分类。
- **营销工具**：设优惠券、特价、打折（见官方电商学习中心）。
- **数据复盘**：千帆后台 → 数据 → 商品总览 / 我的笔记（含蓝链转化）/ 搜索词。诊断从笔记到成交的路径。
- **店铺分**：店铺 → 店铺分，反映综合能力与用户体验，影响转化、复购与平台权益。
- **保证金**：入驻时多数 0 元，但提现/特定情况需缴；规则以官方为准。
